# Расписание БарГУ

Расписание занятий **всех групп Барановичского государственного университета (БарГУ)** — одностраничный сайт в стиле Material UI с данными официального [rasp.barsu.by](https://rasp.barsu.by/stud.php).

**🔗 Сайт:** https://zxkittenxd.github.io/barsu-schedule/

Неофициальный студенческий проект. Без бэкенда, без сборки, без зависимостей — чистые HTML/CSS/JS.

---

## Возможности

- **121 группа**, 5 факультетов: инженерный, экономики и права, педагогики и психологии, лингвистический, ИПКиП
- **Выбор группы** — модалка с поиском (понимает коды с дефисом и без: «ПИТТ-21» = «ПИТТ21») и вкладками факультетов
- **Hash-ссылки** вида `#ПИТТ21/2026-10-05/ПН` — можно поделиться конкретной группой, неделей и днём
- **Неделя ПН–СБ**, переключение дней сегмент-контролом, в т.ч. перетаскиванием (drag) на тач-устройствах
- **Живое обновление** данных с rasp.barsu.by прямо из браузера (через цепочку CORS-реле) + фолбэк: официальный ответ университета во встроенном фрейме
- **Material UI**: карточки с простыми тенями, без тяжёлых backdrop-filter/анимаций, светлая и тёмная темы
- **Мобильная адаптация**: компактный топбар, полноэкранная модалка выбора группы, drag-слайдер дней
- Кэш в `localStorage` — просмотренные группы открываются мгновенно

## Структура репозитория

```
├── index.html          # всё приложение: CSS + разметка + JS (~43 КБ) + BOOT-снимок данных
└── data/
    ├── g000.json …     # расписание групп (по файлу на группу, грузятся лениво по клику)
    └── g120.json
```

## Как работают данные

1. **Снимок.** В `index.html` встроен JSON-снимок: список всех групп + полное расписание группы по умолчанию (ПИТТ21, несколько недель). Остальные группы лежат в `data/gNNN.json` и подгружаются по требованию.
2. **Live-обновление.** При загрузке и по кнопке обновления сайт пытается получить свежее расписание с `rasp.barsu.by` (POST-запрос через публичные CORS-реле: allorigins → cors.lol → corsproxy.io → corsfix) и парсит HTML-таблицы на клиенте.
3. **Фолбэк.** Если реле недоступны — показывается снимок/кэш, а «живой» ответ официального сервера доступен в iframe-панели внизу страницы.
4. Формат `data/gNNN.json`: `meta` (группа, факультет, специальность, `fetchedAt`, доступные недели) + `schedules` (недели → дни → пары → занятия с типом, преподавателем, аудиторией, подгруппой).

> ⚠️ Снимок данных собран **06.10.2026**. Скрипт сбора в репозиторий не входит: для актуализации нужно заново спарсить `rasp.barsu.by`, пересобрать `data/*.json` и BOOT-снимок в `index.html`.

## Локальный запуск

`fetch()` не работает с `file://`, поэтому нужен любой статический сервер:

```bash
git clone https://github.com/zxkittenxd/barsu-schedule.git
cd barsu-schedule
python3 -m http.server 8080
# открыть http://localhost:8080
```
